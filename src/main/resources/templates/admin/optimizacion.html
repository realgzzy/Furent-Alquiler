1. Definición del Problema de Optimización

En la operación diaria de Furent, se reciben $n = 15$ reservas confirmadas de alquiler de mobiliario en múltiples ciudades. La empresa cuenta con una flota propia de $m = 5$ camiones con capacidades limitadas de volumen ($m^3$) y peso ($\text{kg}$), cada uno con un costo fijo diario de activación. El objetivo es determinar simultáneamente qué camiones activar, qué pedidos asignar a cada camión propio y cuáles tercerizar, con el fin de maximizar la utilidad neta total.

2. Variables de Decisión

x_{ik} ∈ {0, 1}

Vale 1 si la orden $i$ se transporta en el camión propio $k$; 0 en caso contrario ($15 \times 5 = 75$ variables).

u_k ∈ {0, 1}

Vale 1 si el camión propio $k$ es activado para la ruta; 0 si se queda en patio sin incurrir en costo fijo ($5$ variables).

z_i ∈ {0, 1}

Vale 1 si la orden $i$ es atendida por la flota propia; 0 si se terceriza con un transportista externo ($15$ variables).

3. Función Objetivo

max Z = ∑i=1..n Ri • zi − ∑k=1..m Fk • uk − ∑i=1..n Ti • (1 − zi)

Donde Ri es el ingreso facturado de la reserva, Fk es el costo fijo diario del camión propio, y Ti es la tarifa del flete tercerizado.

4. Restricciones del Sistema

R1. Capacidad Volumétrica de Flota (m³):
∑i Vi • xik ≤ Ck • uk   ∀ k ∈ K
R2. Capacidad de Carga en Peso (kg):
∑i Pi • xik ≤ Wk • uk   ∀ k ∈ K
R3. Asignación Única y Enlace con Tercerización:
∑k xik = zi   ∀ i ∈ I
R4. No Negatividad e Integralidad Binaria:
xik, uk, zi ∈ {0, 1}

Arquitectura de Integración: Spring Boot 4 + Modelo Matemático

El modelo no es un cálculo aislado, sino una capacidad de software completamente acoplada a la arquitectura MVC de Furent.

Capa 1: Backend Service

FurentOptimizationService

Construye los DTOs de órdenes y camiones, encapsula la formulación de coeficientes y orquesta la solución con gap 0.0%.

Capa 2: Control & REST API

AdminOptimizacionController

Excluye latencias sirviendo rutas web en /admin/optimizacion y endpoints REST JSON desacoplados en /api/resultados.

Capa 3: Interfaz Reactiva

Thymeleaf + Alpine.js

Renderiza KPIs interactivos, barras de progreso de volumen y peso, y notificaciones toast de ejecución inmediata.
